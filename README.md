# Copying Shaping Components Python

This example demonstrates the concept of 'copying the expected but shaping it to your needs' using Python class inheritance. It starts with a generic `ReportGenerator` (the 'expected' base) and then extends it with a `FinancialReportGenerator` to add specific calculations and formatting tailored to financial data.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
